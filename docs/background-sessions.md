# 后台会话与显示端

## 使用契约

- `launch`：后台创建 PTY/shell，返回 Session ID，默认不打开终端窗口。加 `--attach` 时为刚创建的会话打开显示端（与 `attach` 相同：Windows Terminal Tab / macOS Terminal 窗口，不是当前终端，不保证前台焦点）。
- `attach <id>`：Windows 打开 WT Tab，macOS 打开 Terminal 显示端，接入同一会话；不重启程序。
- `send/read/wait-idle`：不依赖显示端，不操作桌面焦点。
- 关闭显示端：断开显示，后台会话继续。`close` 或 shell 退出才结束会话。
- 同一会话最多一个显示端，重复接入直接拒绝；不定位旧 Tab，也没有强制替换参数。

`info/list` 的 `display` 字段为 `detached`、`opening` 或 `attached`。成功 attach 只确认显示连接，不声称窗口已获得操作系统的键盘焦点。后台初始尺寸 100×30；接入时采用显示端尺寸，断开后保留最后尺寸。显示尺寸支持列 20..500、行 5..200。

## 责任划分

```text
Agent CLI ──请求/响应 IPC── 后台宿主（PTY、Screen、插件、显示端占位）
                                  │
                             持续显示连接
                                  │
                         终端显示端（键盘、画面、尺寸）
```

宿主保存唯一显示端状态。`attach` 先申请 15 秒有效的占位，再启动显示端；成功连接解除过期计时，失败取消占位。调用端意外退出时，占位到期释放。显示连接关闭后也释放占位，不终止 shell。

显示连接使用会话登记中的认证凭据及一次性占位票据。接入、快照生成和 PTY 输出在同一个宿主队列中排序，避免初始快照和实时输出之间遗漏或重复。输入继续使用宿主的输入队列；Agent 和人共同操作同一个程序，不提供输入事务隔离。未接入时由 headless xterm 应答其支持的终端查询（例如光标位置）；接入后交给显示终端应答，避免重复响应。

显示端使用 xterm 官方序列化 addon 恢复保留的普通/备用画面，另补充光标显隐、鼠标编码、滚动区域和未完成控制序列；不是回放无界日志。显示端输出队列有大小限制，跟不上时断开显示，后台任务继续。超过容量或无法恢复时明确失败，不用纯文本替代终端画面。

## 生命周期与失败

- 启动参数通过一次性私有文件交接，环境直接继承；不再为窗口启动保存整份环境。
- 宿主诊断写入 `TIDE_STATE_DIR/session-logs/<id>.log`，不包含常规 PTY 输出。
- 启动超时可能表示宿主仍在启动，错误中提供会话 ID 和诊断路径。
- `launch --attach` 的 attach 失败返回 `error.stage: "attach"` 并退出码 1：不自动关闭会话，已发送的输入不会重发，跳过后续等待/抓屏，用 `tide attach <id>` 重试；attach 成功后的等待超时仍是退出码 3，结果里保留 `attached: true`。
- `resize` 在无显示端时直接调整 PTY；已连接时请求可见窗口调整，返回实际结果。
- 宿主退出时发送最终输出及退出码、注销会话；后台 node-pty 清理可能稍后完成。
- 不提供跨宿主崩溃恢复、历史持久化、多显示端、Tab 搜索或强制接管。
- 旧版本宿主不支持新显示协议；升级后重开会话。

## 验证与边界

自动化使用真实 node-pty 和虚拟外层终端，不需要桌面焦点：验证后台启动、单连接占位、认证、断开/过期释放、同一应用 PID 保持、Agent 与显示端输入、尺寸传播、重复接入、重新接入及 shell 退出。

画面恢复测试覆盖颜色、光标、普通/备用缓冲区、待折行、滚动区域、方向键模式、括号粘贴、SGR 鼠标编码和分片 ANSI 序列。不是对所有终端扩展的完整仿真：图像、厂商私有协议及未覆盖的应用需单独验证。原始输出只受 xterm 保留缓冲区约束，不承诺保存整段运行历史。

2026-10-04 Windows Terminal 桌面验收通过：后台 launch 期间按 10ms 采样的前台窗口句柄未改变；attach 打开原会话，重复 attach 拒绝；手动关闭 Tab 后原 TUI PID、计数和 Bash 变量仍保留；重新 attach 显示原状态，键盘与 Agent 输入均有效；close 注销会话并退出显示端。隔离会话已清理，本地证据在 `.tide/tests/desktop-attach/`。macOS 路径仍需在 macOS 上实测，不能由 Windows 结果代替。
