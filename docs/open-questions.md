# 终端读取的当前边界与待验证问题

## 已落地：当前命令预览

公开入口为 `read` / `--with-read`。Bash 4.4+ 通过 OSC 133 标记定位命令；读取只选择当前/最近命令，直到下一条开始，不维护已读历史或保留未读旧命令。

默认返回前 10 行和后 30 行，不超过 40 行完整返回。`--full` 返回同一区域全部保留内容；`--lines N` 返回末尾 N 行（1..2000），两者互斥，不补足旧命令。无标记 shell 和 alternate-screen TUI 以当前画面为范围，默认完整返回。

省略提示不计数、不要求例行补读。只有具体任务缺少证据时才扩大读取。插件 `capture()` 和 idle 检测不受公开读取影响。完整原始日志应在执行命令时落盘。

## 验证范围

单元测试覆盖命令切换、未观察的旧命令、重复读取、进度覆写、首尾边界、完整和尾部读取、光标映射、底部空白、viewport 范围、缓冲淘汰、会话隔离、alternate screen、清屏和 resize。

PTY 集成测试覆盖 Bash 标记、独立与组合读取、新命令替换旧结果及参数校验。仅支持 Bash ≥ 4.4；用户的 Bash 启动配置仍需按实际环境验证。

## 当前限制

- 缺少命令标记时不猜测任务边界，只读当前画面。
- 清屏或尺寸变化重置边界，后续新标记恢复追踪；缓冲区已淘汰内容无法恢复。
- 启动文件、其他 shell 集成或嵌套交互 shell 可能影响标记，需要按真实配置验证。OSC 标记是显示层线索，不是可信执行审计或退出状态。
- 读取、发送和等待不构成原子事务，用户仍可手动输入。
- 不提供历史分页、持久日志或独立读取者状态；本轮不增加字符总量限制。
